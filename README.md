# Fake-Website-for-Personal-Trainer-business
This is a website for a fake personal trainer business called 'McKinless Max Performance', made using HTML, CSS and JavaScript. It consists of a Home Page, About Us Page, Contact Us Page and a Booking Page (where users can create fake bookings for in-person or online lessons). 

Each page will include a navigation menu at the top which includes links to the Home, About and Contact pages. The logo is also present on each side as well as the current date and time.

The Home Page is the first page the user sees when loading the website. It gives a brief description of the business and what is is about (providing fitness lessons for clients) alongside a map and search bar. The map will highlight the fake location of the business (it uses a Google Maps API) and the search bar will showcase the exercises that are on offer at McKinless Max Performance, depending on the characters entered in the search bar.

The next page is the About Us page, it explains the history of the business and its main goal (to make clients fitter and healthier) alongside the lessons on offer (in-person lessons, and the available platforms for online lessons). Furter down is a brief description of the fitness services, including world class gym facilities, qualified personal trainers and nutritional advice. There's also a slideshow with some screenshots. At the bottom of the page is a table that includes the names of each session, what is on offer, the price and buttons that direct the user to the lesson booking page. 

The Booking Page allows users to book lessons, done by entering the type of session (In-Person or Online), the date, start time, lesson length, body parts (multiple can be selected), and an email address (which is optional). Afterwards, the user clicks on the "Confirm your Booking" button and will be sent a downloaded note with the lesson boking details. There is also a button that direct the user to the About page. 

The last page is the Contact page, where users can enter their contact details (will be updated in the future).
